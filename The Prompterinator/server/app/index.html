Get ready countdown
ONE countdown for everything: press play → 3·2·1 → the text moves; press the timer’s Start → same countdown → the timer begins. With the sync toggle on, both fire at the same instant. Press play/Start again during the countdown to cancel it — the next press restarts it from the top.
Mode & position
The main timer counts what is LEFT (yellow); the second shows what has PASSED (red), stacked right underneath it. Set “How much time” to 0 and the main timer sits frozen at 0:00 while the elapsed timer keeps counting. Both sit on the background plate so they never get lost over the text.

The Prompterinator — quick guide

Keyboard commands: Ctrl+T new tab · Ctrl+W close tab (asks if unsaved) · Ctrl+Tab next tab · Ctrl+1…9 jump to tab · Ctrl+S save · Ctrl+O open · Ctrl+F find · Ctrl+Z/Y undo/redo · Ctrl+Enter send to prompter · Ctrl+L lock · Ctrl+K cue box · Ctrl+J start/stop the timer · F1 this help.

LAB features: Voice (transport bar) makes the prompter follow the host's speech through the mic; Lock protects the on-air script; Producer view opens a timer/section window; section headers accept targets and speed (■ INTRO (40–50 s) @60) which drive the timer colors, the bar on the output and automatic speed; *word*, /, |, {slow} inline marks; Find & replace (Ctrl+F), Undo/Redo, Outline, right-click a tab for duplicate/reorder, snapshots under Save ▾, light theme.

Files: Open (or drag & drop) accepts .prompt, .txt/.md, .docx, .xlsx, .pdf, .csv. Save ▾ writes the tab as a .prompt prompter file (script + people colors), plain .txt, or a clean print view for PDF. Ctrl+S = .prompt.

Tabs: each tab is a script. Open several with Open files or +. Only one tab is ON AIR — click Send to prompter on any other tab to switch what the teleprompter shows. Edits to the on-air tab update the prompter live.

Setup: connect the teleprompter monitor by HDMI (extend, not duplicate). Use the ▾ next to Output screen to pick the display (Chrome/Edge ask once for permission to manage windows) — the output opens there, fullscreen. Or click Output screen, drag the window onto that screen and press F. Set Mirror → Horizontal so it reads correctly through the glass. One screen only? Use the fullscreen button.

Templates: the dropdown at the top of the settings panel. A template = look + playback + people, and it auto-saves as you change things. Make one per program (⋮ → New / Duplicate). Every slider has a box to type an exact number and a ↺ to reset it.

Number fields: type a value, or click-and-drag left/right on the box to scrub it (hold Shift for fine steps). ↺ resets.

Cues: the bar under the preview sends a soft banner to the hosts on the prompter ("Wrap up", "Break next"…), or a live countdown ("30 s left"). Presets are editable in the Cues tab and can be bound to the remote.

Live view: the layout toggle puts the script on the left (edit freely, it stays still) and the moving prompter on the right. Drag the divider to resize; hide panels with the corner buttons.

Keys (default): Space play/pause · ←/→ slower/faster · ↑/↓ nudge · PgUp/PgDn sections · Home restart · −/+ text size · M mirror · F fullscreen · N notes. Rebind anything in Remote.

Script: HOST: starts a speaker (colored — manage them in People). [bracketed] = notes. ■ INTRO or an ALL-CAPS line = section (jump chip). … or // = beat. **bold** for emphasis.
